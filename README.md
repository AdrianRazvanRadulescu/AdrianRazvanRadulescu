I write code the way some people keep a journal. I'm not entirely sure when it started, and I can't imagine stopping.

By day I ship things at **[FAN Courier](https://www.fancourier.ro/)** that real people depend on — React frontends, Laravel APIs, databases at logistics scale. On nights and weekends I build whatever I'm curious about: a Shopify inventory SaaS, a writing app for serious writers, an AI agent framework. Sometimes a router simulation in C at 2am just to understand how the internet actually works underneath everything.

I like that code is honest. It doesn't care if you're tired or having a bad week. It works or it doesn't. There's something quietly comforting about that.
